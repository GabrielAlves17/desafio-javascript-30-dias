# Desafio JavaScript — 30 Dias

Este repositório registra minha evolução em um desafio de 30 dias estudando JavaScript.

## Objetivo

Criar consistência, fortalecer a lógica de programação e aprender escrevendo código de verdade — não apenas copiando soluções.

## Regras do desafio

- Meta: estudar em 24 dos 30 dias.
- Sessão normal: 45–60 minutos.
- Em dias cansativos: mínimo de 20 minutos.
- Evitar dois dias seguidos sem estudar.
- Prioridade: código → exercícios → projetos → vídeos.
- Quando travar, tentar raciocinar antes de buscar a solução completa.
