## 🎯 Sobre o desafio

Este repositório acompanha minha evolução durante **30 dias de estudo e prática de JavaScript**.

A proposta não é decorar código nem apenas assistir aulas. O foco é desenvolver autonomia para entender problemas, construir a lógica e chegar às soluções aos poucos.

### Objetivos

- Fortalecer fundamentos de JavaScript
- Melhorar o raciocínio lógico
- Criar consistência estudando programação
- Resolver exercícios sem copiar soluções prontas
- Evoluir de exercícios simples para pequenos projetos
- Registrar minha evolução no GitHub

## 📚 Método de estudo

Minha prioridade durante o desafio é:

**escrever código → fazer exercícios → construir projetos → usar conteúdo de apoio quando necessário**

Em vez de buscar a solução completa ao travar, tento entender o problema e avançar por pistas. O objetivo é desenvolver raciocínio e não dependência de código pronto.
